\textbf{财务管理信息系统} \titlebreak
项目描述：参与财务管理信息系统的开发，系统包括收支管理、报销管理、财务统计分析，实现财务数据的集中管理与查询。主要负责后端部分报销审批流程和收支管理模块。
% 在 itemize 的选项中，使用 topsep=\intraProjectListTopSep 来控制上边距
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item \textbf{后端开发}：基于 \textbf{Spring Boot} 构建了报销审批以及入账的完整链路，设计报销审批状态机模型，包括待提交、审批中、已通过、已驳回、已入账等状态，实现“申请-审批-入账”的完整流程。采用三层架构提升系统可维护性，将请求处理、业务逻辑与数据访问解耦，其中 Service 层负责核心审批逻辑和状态流转规则，包括状态校验、审批节点推进以及入账触发规则，同时面向接口编程，。
    \item \textbf{数据模型及持久化设计}：设计报销，审批与收支相关的数据表，并基于 \textbf{MyBatis} 完成对应数据表的访问层层开发，使用动态SQL，开启数据库自增主键的自动回填机制，实现了主表和明细一对多记录存储，并支持按用户、时间区间与状态的组合查询。
    \item \textbf{数据一致性}：在报销审批，修改与入账过程中引入数据库事务控制，保证报销审批状态更新与收支流水写入的原子性。整体支持并发读写，但采用状态机 + 乐观锁 + 悲观锁混合控制，同时增加审批幂等校验，避免重复审批或重复入账导致的数据异常。
    \item \textbf{工程优化}：设计统一RESTful接口规范与标准化返回结构，引入参数校验与异常拦截机制，包括非法状态流转、重复提交拦截等，提升系统健壮性与前后端联调效率。
\end{itemize}

\textbf{风功率预测与可视化分析平台} \titlebreak
项目描述：独立开发面向风电场的数据分析与预测平台，包括数据处理、模型推理与可视化分析等功能，可以实现风电时序数据的自动清洗、功率预测及结果展示。
% 在 itemize 的选项中，使用 topsep=\intraProjectListTopSep 来控制上边距
\begin{itemize}[nosep, topsep=\intraProjectListTopSep]
    \item \textbf{风功率预测建模}：基于6层GPT-2迁移结构构建时序预测模型，通过冻结部分预训练参数并优化输入输出结构，将风电时序数据进行归一化与滑动窗口patch化处理后映射至Transformer嵌入空间，引入位置编码增强时间依赖建模能力，并结合微调策略完成风电功率预测任务，在低计算开销下实现约4\%–8\%的预测性能提升，并通过REST API封装模型推理能力，向业务系统提供接口以供Spring Boot通过HTTP调用模型服务获取预测结果。
    \item \textbf{后端开发}：基于 Spring Boot + MyBatis ，设计RESTful接口实现风电时序数据的批量上传、分片导入与条件查询。针对大批量历史数据，优化了分页查询的逻辑，并结合索引设计，即风电场ID和时间戳来提升查询性能。
    \item \textbf{数据处理与存储设计}基于 MySQL 设计风电时序数据表结构，以风电场ID和时间戳作为核心查询字段，在数据预处理阶段引入线性插值与四分位距方法进行缺失值修复与异常检测，保证模型输入的数据质量，并实现预测结果与原始数据的分离存储
    \item \textbf{任务调度设计}：基于 Quartz 实现定时预测任务调度机制，支持按风电场维度触发批量预测任务，并设计任务状态流转机制，结合日志记录实现任务执行可追踪性
    \item \textbf{可视化平台} 基于 React + ECharts 构建数据可视化平台，支持历史风电数据、预测结果与真实值的多维对比分析，并提供时间区间筛选与风电场维度切换能力
    \item \textbf{系统优化}：引入 Redis 缓存高频访问的预测结果数据，减少重复模型推理调用；针对热点风电场数据增加缓存命中策略，降低高并发查询场景下接口响应延迟
\end{itemize}
